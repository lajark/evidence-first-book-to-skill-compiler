## 推荐测评顺序

```text
《孙子兵法》
→ 验证电子书读取、结构识别和基础提炼是否跑通

《番茄工作法图解》
→ 验证程序能否把知识转成有状态、有异常路径的可执行流程

《微习惯》
→ 验证程序能否保留理论、机制、八步流程、八条规则和反直觉边界
```

## 标准评测流程

1. 固定原始电子书版本和程序版本。
2. 生成候选 Skill 包，禁止人工修订后再测。
3. 由评测 AI 阅读完整 Skill 包。
4. 按对应基准逐项记录证据并评分。
5. 实际运行基准中的场景测试。
6. 应用扣分项、封顶规则和专项通过条件。
7. 输出人类可读报告与机器可读 JSON。
8. 保存程序版本、输入文件哈希、候选 Skill 哈希和评测模型信息，便于复测。

## 注意事项

- 三份基准评估的是“从书到可用 Skill 的转化质量”，不是传统读书摘要质量。
- 不应以篇幅长短代替质量判断；高分 Skill 通常会把执行指令、知识库、模板和示例分层。
- 现代扩展知识不是禁止项，但必须与原书内容清楚区分。
- 不同中文版本的译名差异不应扣分，除非造成实质性误解。
