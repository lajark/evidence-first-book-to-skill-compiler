# 《微习惯》Skill 提炼质量评估打分表

## 1. 测评目标

本基准用于评估程序能否提炼复杂方法论，而不只是抽取“从小事开始”这一表层口号。

高质量候选 Skill 应保留以下链条：

```text
动机不稳定、意志力有限
→ 把每日最低行动缩小到“几乎不可能失败”
→ 用少量意志力跨过启动阻力
→ 每日完成最低标准并允许额外行动
→ 形成成功反馈、自我效能和稳定重复
→ 观察习惯化迹象，而非过早抬高要求
```

候选 Skill 必须能区分“最低要求”和“额外完成”，并能防止用户因状态变好而不断提高最低标准。

## 2. 评测对象与版本容差

- 评测对象：由《微习惯》生成的完整 Skill 包。
- 不要求复述书中全部心理学研究，但必须保留方法论所依赖的关键因果关系。
- “微习惯”“小到不可失败”“愚蠢般微小”等译法均可接受。
- 不得与《原子习惯》《Tiny Habits》等其他方法混写；外部方法只能标为扩展。
- 原书主要用于建立积极习惯，不是治疗成瘾、严重心理问题或替代医疗支持的方案。


## 3. 通用评分方法

### 3.1 单项评分锚点

每个评分项先给出 `rating`，再换算为得分：

| rating | 含义 | 得分比例 |
|---:|---|---:|
| 0 | 缺失、不可用，或与原书明显冲突 | 0% |
| 1 | 仅提及概念，存在严重缺口或无法执行 | 25% |
| 2 | 基本正确，但覆盖、结构或执行性不足 | 50% |
| 3 | 正确且可用，仅有少量非关键缺口 | 75% |
| 4 | 准确、完整、结构清晰，可直接稳定调用 | 100% |

计算方式：

```text
item_score = item_max_score × rating ÷ 4
total_score = Σ item_score - penalties
```

允许保留 0.25 分；最终总分四舍五入至 1 位小数。

### 3.2 证据规则

- 只对候选 Skill 中**可定位、可验证**的内容计分。
- 每个评分项必须记录证据位置，例如：`SKILL.md > 使用流程 > 第2步`。
- 同一证据可以支持多个相互独立的评分项，但不得对同一能力重复计分。
- 仅存在于原始电子书、程序日志或评测者常识中，而未进入候选 Skill 的内容，不计分。
- 术语、译名、章节名允许存在版本差异；语义等价即可。
- 候选 Skill 新增的通用知识必须明确标为“扩展建议”或“非原书内容”，否则按混淆来源处理。

### 3.3 等级与通过条件

| 总分 | 等级 | 结论 |
|---:|---|---|
| 90–100 | S | 高质量，可作为正式 Skill 使用 |
| 80–89.9 | A | 良好，少量修订后可用 |
| 70–79.9 | B | 基本通过，仍需补齐关键缺口 |
| 60–69.9 | C | 未通过，提炼质量不稳定 |
| <60 | D | 未通过，不具备可靠使用价值 |

除总分外，还必须同时满足本文件规定的“专项通过条件”。

### 3.4 封顶规则

出现下列情况时，即使加总分更高，也执行封顶：

| 问题 | 总分上限 |
|---|---:|
| 文件无法解析、入口缺失，AI 无法知道如何调用 | 20 |
| 产物实质上只是读书摘要，没有可执行的 Skill 行为 | 45 |
| 核心方法被系统性误解或反向表达 | 55 |
| 大量编造原书不存在的原则，且未标注为扩展 | 60 |
| 依赖大段复制原书才能工作，缺乏转化与抽象 | 65 |

## 6. 场景测试集

### CASE-MH-01｜阅读目标反复失败

```yaml
input:
  goal: "每天读30页"
  history: "连续制定三次计划，都在一周内中断"
expected_behavior:
  - "追问真正目的和阻力"
  - "把最低标准缩小到极易完成，例如读一页或打开书读一小段"
  - "允许多读，但不要求每天30页"
  - "定义线索、记录和奖励"
```

### CASE-MH-02｜一天做了很多，要求立刻加码

```yaml
input:
  current_minimum: "每天1个俯卧撑"
  today_bonus: "额外做了30个"
  request: "明天起把最低标准改成30个"
expected_behavior:
  - "认可额外完成"
  - "明确额外完成不等于新的最低要求"
  - "维持微小基线，除非经过稳定观察和审慎调整"
fail_if:
  - "立即把30个设为每日硬性最低要求"
```

### CASE-MH-03｜连续漏做并自责

```yaml
input:
  issue: "连续三天没有完成写作微习惯，认为自己没有自律"
expected_behavior:
  - "不进行人格归因或羞辱"
  - "检查动作是否仍然足够小、线索是否有效、环境是否变化"
  - "进一步缩小并从当天恢复"
  - "不要求惩罚性补写"
```

### CASE-MH-04｜等待动力

```yaml
input:
  statement: "等我有动力时再开始锻炼"
expected_behavior:
  - "指出动力波动，不把动力作为行动前提"
  - "设计只需少量意志力的最低动作"
  - "让行动本身创造后续动力或额外次数的可能"
```

### CASE-MH-05｜戒除成瘾行为

```yaml
input:
  request: "请只用微习惯帮我戒掉严重赌博成瘾"
expected_behavior:
  - "说明该方法主要用于建立积极习惯，不能替代专业成瘾支持"
  - "建议寻求合适的专业帮助和现实支持系统"
  - "可把微习惯作为辅助性的积极行为，但不得承诺治疗效果"
```

### CASE-MH-06｜判断是否已形成习惯

```yaml
input:
  duration: "坚持21天"
  observation: "每天仍需要强烈提醒，阻力很高"
  question: "是不是已经形成习惯，可以大幅提高要求？"
expected_behavior:
  - "不以21天作为唯一判据"
  - "观察自动性、阻力、身份认同和遗漏后的感受"
  - "在阻力仍高时维持或缩小基线"
```
