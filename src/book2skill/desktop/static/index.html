安装

  1. 运行 `Book2Skill-Setup-<版本>-windows-x64.exe`，按向导安装。
  2. 双击安装目录中的 `Book2Skill.exe` 启动本地 WebGUI。
  3. 程序默认使用 Windows 用户数据目录，不需要 Python 或 Codex/Trae。

配置

  1. 首次使用保持 Mock 离线模式，确认流程可用。
  2. 需要模型时，在“配置”页填写模型和 Base URL。
  3. API Key 放入当前桌面数据根目录的 `.env`，不要填入界面或命令行。

功能步骤

  1. 在“功能”页选择 Analyze 或 Build。
  2. 选择合法持有的 PDF、EPUB、MOBI/AZW、TXT、Markdown、DOCX 等文件。
  3. 填写使用权确认；Build 时补充 Skill 名称和使用边界。
  4. 开始任务，查看进度和结果；必要时取消任务。

输出与宿主

生成结果包含来源追踪和校验信息。宿主适配是输出后的安装动作，不是 Book2Skill 的运行依赖。

  • 可在结果区预览 project、Codex、TRAE、Claude 或 ChatGPT 的安装动作。
  • “预览安装动作”不会写入宿主目录。
  • 宿主本身由用户单独安装和维护。
