# Code of Conduct

Book2Skill is a small technical project for people who care about trustworthy knowledge tooling. Participants are expected to be respectful, specific, and willing to revise claims when evidence changes.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, deliberate disclosure of private material or credentials, submission of copyrighted source text without permission, and attempts to bypass DRM or project security boundaries.

Report conduct concerns privately to the repository maintainer. Security vulnerabilities and leaked credentials must follow [SECURITY.md](SECURITY.md), not a public issue.
